# Grace Community Church — Web App

A simple, modern single-page church website built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview
```

## Customize

- **Sections:** Hero, services, about, ministries, sermons, events, first-time FAQ, giving, and visit — all in `src/components/`.
- **Branding & copy:** Edit section components in `src/components/`.
- **Colors & fonts:** Update CSS variables in `src/index.css`.
- **Church name:** Search for "Grace Community" across the project.
